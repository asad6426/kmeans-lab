# K-Means Lab

Segment 8 shoppers into 2 clusters and watch distances and centroids update step by step.

**[Open the live lab](https://asad6426.github.io/kmeans-lab/)**

## What it covers

- The raw dataset shown before any calculation
- Animated distance and centroid walkthrough
- Short-answer quiz
- Essay prompts and glossary

## Details

- **Audience:** Students starting unsupervised learning
- **Language:** English
- **Built with:** Plain HTML, CSS and JavaScript, with no build step

## Run it locally

Open `index.html` in a browser.
